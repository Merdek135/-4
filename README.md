# Практическая работа №4
# Цель практической работы

  В этом модуле вы узнали, как работать с системой контроля версий Git. Эта практическая работа позволит углубить знания по следующим темам:
  
 *- Основы работы с Git: создание, клонирование и управление репозиториями.*
 
 *- Версионирование проектов: отслеживание и сохранение различных версий кода.*
 
 *- Командная работа через Git: практика пул-реквестов.*
 
 *- Жизненный цикл разработки: от создания новой функции до её интеграции.*
 
 *- Документирование в проектах: составление README.md.*
 
 *- Слияние изменений: интеграция новых функций без конфликтов.*

# Необходимые задачи для квалификации работы:

  1. Создайте Git-репозиторий для проекта, например RobotMotorsControl, на платформе GitHub (или GitLab). Клонируйте репозиторий на свой компьютер.
     
  2. Создайте файлы в каталоге репозитория, например README.md и motors_control.py. Реализуйте скрипт для управления двигателями робота (например, на Python).
     
  3. Сохраните изменения в репозитории с помощью команд git add, git commit и git push (initial commit).
  
  4. Создайте новую ветку для внесения улучшений (git checkout -b feature_branch_name).
  
  5. Внесите улучшения в код в новой ветке (например, функции плавного изменения скорости или обработки пользовательского ввода).
  
  6. Сохраните внесённые улучшения в репозитории.
  
  7. Создайте пул-реквест для слияния изменений с основной веткой (на GitHub/GitLab).
  
  8. Опционально: дождитесь ревью кода от куратора и внесите необходимые правки, если потребуется.
  
  9. Закройте пул-реквест и завершите слияние изменений с основной веткой.
  
10. Оформите краткий отчёт в файле README.md в Git-репозитории. 

# Используемые инструменты

- Python 3
- Git
- GitHub
- Командная строка

## Ход работы

1. Создан репозиторий `RobotMotorsControl` на GitHub.
2. Репозиторий склонирован на локальный компьютер.
3. Созданы файлы `README.md` и `motors_control.py`.
4. Реализован базовый скрипт управления двигателями.
5. Выполнен initial commit и отправка изменений в основную ветку `main`.
6. Создана ветка `feature/smooth-speed-control`.
7. Добавлены плавное изменение скорости и обработка пользовательского ввода.
8. Изменения сохранены, закоммичены и отправлены в удалённый репозиторий.
9. Создан пул-реквест для слияния ветки с `main`.
10. Пул-реквест рассмотрен и объединён с основной веткой.

## Результат

Создан Git-репозиторий с проектом управления двигателями робота. Основная
ветка содержит первоначальную версию проекта, а отдельная ветка — улучшения:
плавное изменение скорости и интерактивное управление через команды
пользователя. Изменения объединены с основной веткой через пул-реквест.
