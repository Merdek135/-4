# RobotMotorsControl

Проект для управления двигателями робота. Реализован простой Python-скрипт,
который имитирует управление левым и правым двигателями, поддерживает команды
пользователя и плавное изменение скорости.

## Цель работы

Создать Git-репозиторий, реализовать скрипт управления двигателями робота,
выполнить первый коммит, разработать улучшение в отдельной ветке и оформить
пул-реквест для слияния изменений с основной веткой.

## Используемые инструменты

- Python 3
- Git
- GitHub
- Командная строка

## Структура проекта

- `README.md` — описание проекта и отчёт о выполненной работе
- `motors_control.py` — скрипт управления двигателями робота

## Реализованный функционал

- Управление двумя двигателями робота
- Ограничение скорости в диапазоне от -100 до 100
- Команды: forward, backward, left, right, stop, exit
- Плавное изменение скорости двигателей
- Обработка прерывания работы с клавиатуры

## Ход работы

1. Создан репозиторий `RobotMotorsControl` на GitHub.
2. Репозиторий склонирован на локальный компьютер.
3. Созданы файлы `README.md` и `motors_control.py`.
4. Реализован базовый скрипт управления двигателями.
5. Выполнен initial commit и отправка изменений в основную ветку `main`.
6. Создана ветка `feature/smooth-speed-control`.
7. Добавлены плавное изменение скорости и обработка пользовательского ввода.
8. Изменения сохранены, закоммичены и отправлены в удалённый репозиторий.
9. Создан пул-реквест для слияния ветки с `main`.
10. Пул-реквест рассмотрен и объединён с основной веткой.

## Команды Git

```bash
git clone [https://github.com/](https://github.com/)<ваш_логин>/RobotMotorsControl.git
cd RobotMotorsControl
git add README.md motors_control.py
git commit -m "Initial commit: add project documentation and motors control script"
git push -u origin main
git checkout -b feature/smooth-speed-control
git add motors_control.py
git commit -m "Add smooth speed control and user command handling"
git push -u origin feature/smooth-speed-control
```

## Результат

Создан Git-репозиторий с проектом управления двигателями робота. Основная
ветка содержит первоначальную версию проекта, а отдельная ветка — улучшения:
плавное изменение скорости и интерактивное управление через команды
пользователя. Изменения объединены с основной веткой через пул-реквест.
